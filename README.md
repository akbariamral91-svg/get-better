# Get Better — «هر قدم، نزدیک‌تر به هدف»

(نام داخلی پروژه و شناسهٔ بسته همچنان `masir_ghabuli` است تا ساخت و به‌روزرسانی نصب‌شده‌ها دچار مشکل نشود؛ فقط نام نمایشی تغییر کرده است.)

اپلیکیشن اندرویدی آفلاین (Flutter) برای برنامه‌ریزی روزانه و آمادگی آزمون ورودی مدرسه نمونه دولتی.

## وضعیت صادقانهٔ این تحویل
- کد منبع کامل نوشته شده است، اما **در محیط ساخت این پروژه Flutter/Android SDK و اینترنت وجود نداشت**؛ بنابراین
  **کامپایل، اجرا روی شبیه‌ساز/گوشی، اجرای تست‌های Dart و ساخت APK انجام نشده است.**
- فقط این موارد واقعاً اجرا و بررسی شدند: الگوریتم تبدیل تاریخ شمسی (با Python روی ۳ تاریخ مرجع)، اعتبار SQL طرح پایگاه داده و
  یکتایی دفتر XP (با sqlite)، و تعادل پرانتز/آکولاد فایل‌های Dart.
- انتظار داشته باش در اولین `flutter analyze` / `flutter run` چند خطای کوچک (مثلاً تفاوت نسخهٔ API) ظاهر شود؛ باید رفع شوند.
- فونت وزیرمتن به‌دلیل نبود اینترنت داخل پروژه قرار نگرفت (پایین‌تر توضیح داده شده).

## تغییرات نسخهٔ ۱٫۱ (مرحلهٔ اول ارتقا)
- نام نمایشی برنامه: **Get Better** (برچسب اندروید در `android_overrides/AndroidManifest.xml`، عنوان‌ها و اعلان‌ها). اگر قبلاً `setup.sh` را اجرا کرده‌ای، دوباره اجرا کن (یا همان فایل manifest را کپی کن).
- تم تیره (پیش‌فرض) و روشن: پالت در `lib/theme/app_theme.dart`، دسترسی با `context.colors`. انتخاب کاربر در SharedPreferences ذخیره می‌شود. دکمهٔ کوچک در سربرگ خانه و گزینهٔ «تم برنامه» در تنظیمات.
- ناوبری چهارتایی: خانه (امروز + برنامه روزانه) · پیشرفت (آمار + نقشهٔ مسیر) · یادداشت‌ها · مرور (مسیر یادگیری). صفحهٔ پیش‌فرض خانه است.
- پایگاه داده نسخهٔ ۲ (ارتقای امن، داده‌های قبلی دست‌نخورده): جدول‌های `notes`، `tags`، `note_tags` (ارتباط چند‌به‌چند) و `day_events`. حذف برچسب یادداشت‌ها را حذف نمی‌کند. پشتیبان‌گیری/بازیابی جدول‌های جدید را هم شامل می‌شود و پشتیبان نسخهٔ ۱ هنوز قابل بازیابی است.
- API ذخیره‌سازی در `AppState`: `saveNote`، `toggleNotePin`، `deleteNote`، `saveTag`، `deleteTag`، `saveDayEvent`، `deleteDayEvent`.
- آیکون‌ها: `lib/utils/app_icons.dart` (کلید متنی ← آیکون Material، گروه‌های کارها/یادداشت‌ها/اتفاقات و انتخاب‌گر `showIconPicker`).
- فونت وزیرمتن: با `bash tool/get_font.sh` دانلود و ثبت می‌شود (فقط Regular و Bold).

## تغییرات مرحلهٔ دوم (نسخهٔ ۱٫۲)
- **یادداشت‌ها**: کارت‌های مستطیلی دو‌ستونه، سنجاق (سنجاق‌شده‌ها اول)، جست‌وجو در عنوان و متن، صفحهٔ ایجاد/ویرایش/حذف با نمایش کامل متن، برچسب‌های ساخت‌کاربر (نام و رنگ دلخواه، چند برچسب برای هر یادداشت)، فیلتر با برچسب و صفحهٔ مدیریت برچسب‌ها (حذف برچسب هیچ یادداشتی را پاک نمی‌کند).
- **اتفاقات روز**: چند اتفاق در روز، عنوان اختیاری، تاریخ و ساعت قابل ویرایش، آیکون Material، گروه‌بندی بر اساس تاریخ، ویرایش و حذف.
- **آیکون‌ها**: انتخاب‌گر آیکون (`IconPickerField`) در فرم مأموریت‌ها و اتفاقات؛ کلید آیکون در پایگاه داده ذخیره می‌شود. پایگاه داده به نسخهٔ ۳ ارتقا یافت (ستون اختیاری `icon` برای مأموریت‌ها؛ داده‌های قبلی دست‌نخورده).
- **مسیر پیشرفت**: مسیر بصری پیوسته از پایین به بالا با هدف «قبولی در مدرسه نمونه دولتی بشارتی» در بالاترین نقطه؛ وضعیت هر مرحله (تکمیل‌شده/فعال/قفل‌شده) و درصد پر شدن مسیر فقط از داده‌های واقعی برنامه محاسبه می‌شود. مسیر انگیزشی است و ساختار رسمی آزمون نیست.
- **شمارش معکوس آزمون**: تاریخ را خود کاربر از «تنظیمات ← آزمون» (یا دکمهٔ صفحهٔ پیشرفت) وارد می‌کند؛ تا تعیین نشود پیام مناسب نمایش داده می‌شود و هیچ تاریخ پیش‌فرضی وجود ندارد. تاریخ آزمون در پشتیبان هم ذخیره می‌شود.
- **فونت**: تم و همهٔ اجزا روی خانوادهٔ `Vazirmatn` تنظیم شده‌اند. `tool/get_font.sh` بازنویسی شد (چند منبع، اعتبارسنجی سرفصل TTF و حجم، ثبت خودکار در pubspec فقط پس از دریافت موفق).

### وضعیت فونت (مهم)
فایل‌های `Vazirmatn-Regular.ttf` و `Vazirmatn-Bold.ttf` **هنوز در پروژه نیستند**؛ محیط ساخت این مرحله هم اینترنت نداشت. تا اجرای `bash tool/get_font.sh` روی سیستم خودت، برنامه با فونت سیستم نمایش داده می‌شود. بلوک `fonts:` عمداً در pubspec ثبت نشده، چون ثبت بدون فایل باعث خطای build می‌شود.

### وضعیت آزمایش
در محیط این مرحله Flutter/Dart و اینترنت نبود: `flutter pub get`، `flutter analyze`، `flutter test` و ساخت APK **اجرا نشده‌اند**. تست‌های جدید در `test/stage2_test.dart` نوشته شده‌اند اما اجرا نشده‌اند.

## پیش‌نیاز
Flutter ‏3.24 یا بالاتر، Android SDK، Android Studio یا خط فرمان.

## راه‌اندازی
```bash
bash setup.sh          # flutter create (فقط اندروید) + کپی AndroidManifest آماده + pub get
```
### ۱) desugaring برای اعلان‌ها (دستی)
در `android/app/build.gradle` (یا `build.gradle.kts`) این‌ها را اضافه کن:

Groovy:
```gradle
android {
    compileOptions {
        coreLibraryDesugaringEnabled true
        sourceCompatibility JavaVersion.VERSION_1_8
        targetCompatibility JavaVersion.VERSION_1_8
    }
}
dependencies {
    coreLibraryDesugaring 'com.android.tools:desugar_jdk_libs:2.1.4'
}
```
Kotlin DSL:
```kotlin
android { compileOptions { isCoreLibraryDesugaringEnabled = true } }
dependencies { coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.1.4") }
```
اگر هنگام build دربارهٔ `compileSdk` خطا گرفتی، آن را روی ۳۵ یا بالاتر بگذار.

### ۲) فونت وزیرمتن (اختیاری ولی توصیه‌شده)
`Vazirmatn-Regular.ttf` و `Vazirmatn-Bold.ttf` را از مخزن رسمی وزیرمتن بگیر، در `assets/fonts/` بگذار و بلوک
`fonts:` در `pubspec.yaml` را از حالت کامنت خارج کن. بدون آن، فونت سیستم استفاده می‌شود.

### ۳) اجرا، تست، ساخت
```bash
flutter analyze
flutter test
flutter run
flutter build apk --release      # خروجی: build/app/outputs/flutter-apk/app-release.apk
```
APK release با کلید debug امضا می‌شود؛ برای انتشار، keystore خودت را طبق مستندات Flutter تنظیم کن.

## قابلیت‌ها (نوشته‌شده؛ هنوز اجرا و آزمایش نشده)
- مأموریت: ساخت/ویرایش/حذف (با تأیید)/تکمیل، اعتبارسنجی فرم، XP بر اساس زمان و اولویت، انتقال به روز دیگر با تأیید، نمای ۷ روزه
- XP اتمیک: تراکنش + قید UNIQUE روی دفتر XP (تکمیل مجدد یا لمس مکرر امتیاز دوباره نمی‌دهد؛ حذف مأموریت امتیاز را پاک نمی‌کند)
- سطح، نوار پیشرفت، انیمیشن ارتقای سطح، ۶ دستاورد با شرط و زمان دریافت
- مسیر یادگیری: درس ← فصل ← مبحث، وضعیت تسلط، ثبت تمرین/آزمون/مرور، یادداشت و اشتباهات، زمان مرور بعدی، اولویت مباحث ضعیف
- «تسلط تأییدشده» فقط با معیار: دو ثبت آخر در دو روز متفاوت، هرکدام ≥۱۰ سؤال و دقت ≥۸۰٪
- آمار از داده واقعی؛ بدون داده پیام راهنما نشان داده می‌شود (داده ساختگی ندارد)
- نقشهٔ ۷ مرحله‌ای با شرط بازشدن (چارچوب انگیزشی، نه ساختار رسمی آزمون)
- حالت بازگشت پس از ≥۳ روز وقفه: بدون سرزنش، امتیازها حفظ می‌شود، پیشنهاد مأموریت ۱۰ دقیقه‌ای
- یادآوری صبح و برنامه‌ریزی شبانه (اعلان محلی روزانه، درخواست مجوز اندروید ۱۳+، بازگرداندن بعد از ریستارت)
- گزارش پایان روز و میان‌بر برنامه‌ریزی فردا
- پشتیبان/بازیابی (متن JSON از طریق کلیپ‌بورد) و پاک‌سازی کامل با تأیید

## محدودیت‌های شناخته‌شده
- اعلان‌ها با زمان‌بندی غیردقیق‌اند (بدون نیاز به مجوز Exact Alarm)؛ ممکن است چند دقیقه تأخیر داشته باشند و در برخی گوشی‌ها
  سیستم باتری باید برای برنامه آزاد شود.
- پشتیبان‌گیری فایلی نیست؛ از کلیپ‌بورد استفاده می‌کند.
- حالت بازگشت فقط مأموریت کوتاه پیشنهاد می‌دهد؛ حجم روز را خودکار بازچینی نمی‌کند.
- مقایسهٔ سرعت آزمون‌ها ساده است (کمترین ثانیه بر سؤال در آزمون‌های ≥۱۰ سؤال) و سختی آزمون‌ها را در نظر نمی‌گیرد.
- هیچ محتوای درسی یا پیش‌بینی احتمال قبولی در برنامه نیست.
